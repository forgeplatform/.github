# Contributing to Forail Platform

This is the organization-wide entry point for contributing to any
[Forail Platform](https://github.com/forail-platform) repository.

## Where to start

- Read the **centralized contributing guide** for git workflow, commit
  conventions, and the PR process:
  <https://forail-platform.github.io/dev/contributing.html>
- Browse the docs: <https://forail-platform.github.io/>

## Quick rules

- Open an issue on the **relevant repository** using the provided issue forms.
- Keep commits focused; commit messages are short and imperative (one line).
- Run the repository's test suite and CI checks before opening a PR.
- By contributing you agree your work is licensed under Apache 2.0.

## Reporting security issues

Do not use issues or pull requests for security reports. See
[SECURITY.md](SECURITY.md) — email **office@krletron.xyz** privately.
